# Synthetic dataset
Six hundred synthetic student rows plus seven linked source files are included in `raw/`. Primary CSVs have unique student IDs per source; missing values are blank and not imputed. Reproducible seed: 20261013. Validate: `python -m pytest ai-service/tests` and use `npm --prefix backend run import:dataset` after configuring MongoDB. For duplicate-import testing, repeat the import; MongoDB upserts use `student_id` as key. The importer resolves its bundled CSV directory relative to its script (or `DATASET_DIR`), so it works from both the repository and the backend deployment image. Do not use synthetic data to make real student decisions.
